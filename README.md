# ai-automation

This repository contains a collection of AI automation tools.

## copilot-review-bot

This tool uses our @xrplf-bot to request Copilot to review PRs.

## Pre-commit hooks

This repository uses [pre-commit](https://pre-commit.com) to check Markdown
and shell script files before each commit. Do these steps after you clone
the repository:

1. Install pre-commit. Run `pip install pre-commit` or `brew install
   pre-commit`.
2. Run `pre-commit install` in the repository root. This command installs
   the git hook.
3. Test the hook. Run `pre-commit run --all-files`.

After setup, four hooks run on every commit:

* `markdownlint-cli2` checks Markdown files. It only reports problems; you
  fix them by hand.
* `shfmt` formats shell scripts and rewrites them in place.
* A local hook adds `${VAR}` braces around shell variables that are missing
  them, also rewriting the file in place.
* `shellcheck` checks shell scripts for common bugs. Like markdownlint, it
  only reports problems; you fix them by hand.

The two hooks that rewrite files also block the commit on the run that made
the change, so run the commit again once they are done. To check only the
staged files, run `pre-commit run`. To check every hook against every file,
run `pre-commit run --all-files`.

### If `pre-commit install` refuses to run

Some machines set `core.hooksPath` in git config, for example to run a
different hook across every repository. If your machine does this,
`pre-commit install` refuses to run and shows this message:

```text
Cowardly refusing to install hooks with `core.hooksPath` set.
```

To fix this for this repository only, do these steps:

1. Point the hooks path back at the normal location, for this repository
   only. Run:

   ```bash
   git config core.hooksPath .git/hooks
   ```

2. Create the file `.git/hooks/pre-commit` with this exact content, then
   run `chmod +x .git/hooks/pre-commit`:

   ```bash
   #!/usr/bin/env bash
   # File generated by pre-commit: https://pre-commit.com
   # ID: 138fd403232d2ddd5efb44317e38bf03

   # start templated
   INSTALL_PYTHON=/opt/homebrew/opt/pre-commit/libexec/bin/python3.14
   ARGS=(hook-impl --config=.pre-commit-config.yaml --hook-type=pre-commit)
   # end templated

   HERE="$(cd "$(dirname "$0")" && pwd)"
   ARGS+=(--hook-dir "$HERE" -- "$@")

   if [ -x "$INSTALL_PYTHON" ]; then
       exec "$INSTALL_PYTHON" -mpre_commit "${ARGS[@]}"
   elif command -v pre-commit > /dev/null; then
       exec pre-commit "${ARGS[@]}"
   else
       echo '`pre-commit` not found.  Did you forget to activate your virtualenv?' 1>&2
       exit 1
   fi
   ```

3. Test the hook. Run `pre-commit run --all-files`.

This fix only changes this repository. It does not change the hooks path,
or any hook, for any other repository on your machine.
